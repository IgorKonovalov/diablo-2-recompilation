- [2026-10-11] from architect → reverser: `TC_BuildAutoTCs` `0x006541C0` details seen during the plan 0002 review, to record in a finding before `items/tc` cites them. (a) The type code is rebuilt from the itemtypes code link by `0x006BD180`, which writes each space as NUL, so `bow ` becomes `"bow"` and the TC name is `bow3`…`bow96`. If that lookup fails, no TC is allocated for that level, which would shift the numbering. (b) Each TC is created with `picks` 1, `group` 0 and `level` = L − 3 (`0x0065428B`–`0x00654297`). (c) Item filter, in order: `+0x12A` = 0, `+0x133` ≠ 0, `0x00629A90(item, t)`, then, unless the type record offset is `0x21D8` (itemtypes record 38), the item must not also be of type 38 (`0x006542DF`–`0x006542F2`). After that the `+0x0FD` window applies. (d) The entry probability is `max(1, byte +0x1E)` of the record returned by `0x00555C90(item +0x11E)`, and entry flag `0x10` is set when the item's `+0xF6` word ≥ 100 (`0x00654309`–`0x00654361`).
