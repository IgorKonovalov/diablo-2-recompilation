## Purpose

One row per missile class: arrows, bolts, novas, clouds, walls, explosions, debris, the invisible "maker" and
"control" missiles that spawn others, and pure client effects. A row holds the missile's server and client function
numbers, their parameters and formulas, its motion (velocity, acceleration, lifetime), its collision rules, its
physical and elemental damage, the missiles it creates (sub-missiles, on-hit missiles, the explosion) and its art,
light and sound. Readers: `skills/missiles` ([plan 0045](../plans/0045-skills-missiles-machinery.md)); so far
`data/calc` (the missile formula variables), `combat` (the hit path, named) and `drlg/collision` (the creation mark).
Leads: no lead; derived from data.

## Row identity

- `[C]` The `.bin` is a u32 record count (684) and 684 records of 420 bytes, one per `.txt` row in order
  ([excel-bin.md](../formats/excel-bin.md)); the full-record loader allocates `0x1A4`-byte records into
  `DataTables+0xB64`, with the name tree at `+0xB68` and the count at `+0xB6C`
  ([data/0001 § 4](../findings/data/0001-excel-loader.md#4-record-size-corroboration-all-88-bin-tables),
  struct:DataTables+0xB64).
- `[C]` `Id` equals the row index in all 684 rows (`skills_survey.py`: `ms_id_is_row=684`). The name key `Missile` is
  not compiled; the columns that name a missile (Skills `srvmissile*`/`cltmissile*`, this table's links) store the row
  index of the name. (tbl:Missiles.txt:Id)
- `[I]` The missile formula reader takes a missile's record by its class (`sub_0046ACE0_MissileRec`,
  fn:sub_0046ACE0_MissileRec@0x0046ACE0; [data/0005](../findings/data/0005-calc.md)).

## Columns

`[C]` layout: `python3 -I tools/excel_bin.py diff workspace/merged/data/global/excel missiles`: 684 records × 146 mapped
fields = 99 864 cells, **0 mismatches** (20 calc cells are expressions: offset present, bytecode not decoded).
`excel_bin.py unknown … missiles` lists only zero bytes (`+0x002`, `+0x006..+0x007`, `+0x0E5..+0x0E7`, `+0x18F`,
`+0x197..+0x19B`, `+0x1A3`). Offsets are the ones `excel_bin.py probe` finds; the seven calc offsets are those of the
loader's descriptor ([data/0005 § 1](../findings/data/0005-calc.md), plan 0035). Observed values are from the `.txt`
(684 rows), generated by script. **Meaning** is the column name's plain reading, `[L]`, unless it carries its own tag.
The 23 `*…` comment columns are not listed (not compiled). Columns blank in every row are placed by the stride of
their run (`xoffset`, `SubMissile3`, `HitSubMissile2..4`, `DmgSymPerCalc` by the descriptor).

### Encodings particular to this table

- `[C]` **Packed flags** `+0x004..+0x005`: 16 columns, one bit each (`LastCollide`, `Explosion`, `Pierce`, `CanSlow`,
  `CanDestroy`, `ClientSend`, `GetHit`, `SoftHit` in `+0x004` bits 0–7; `ApplyMastery`, `ReturnFire`, `Town`, `SrcTown`,
  `NoMultiShot`, `NoUniqueMod`, `Half2HSrc`, `MissileSkill` in `+0x005` bits 0–7), not in header order. A bit is set by
  any non-zero cell: `Explosion` and `NoMultiShot` hold `2` on one row each and their bit is set
  ([excel-bin.md](../formats/excel-bin.md)). The other boolean columns (`Collision`, `CollideKill`, `ToHit`, …) are whole
  bytes. (tbl:Missiles.txt:Explosion, tbl:Missiles.txt:NoMultiShot)
- `[C]` **A non-digit function cell.** Row 568 `royalstrikechainlightning` holds `*16` in `pCltHitFunc` and `*12` in
  `pSrvHitFunc`; the compiler's integer parse turns them into 64 952 and 64 948 (u16; −584 and −588 as s16: every
  character adds `byte − 0x30` to `value × 10`, [excel-bin.md § Integers](../formats/excel-bin.md#integers)), so the
  record names server hit function 64 948. What the game does with it is plan 0045 Phase 1.2 (`ms_func_nondigit_cells=1`). (tbl:Missiles.txt:pSrvHitFunc)
- `[C]` **`EType`** is an [ElemTypes](ElemTypes.md) row index (u8), matched on the 4-character code: the 20 cells that
  hold a single space store 0, the row of the blank code (`None`), like the blank cells (`ms_etype_space=20`).
  (tbl:Missiles.txt:EType)
- `[C]` **`SrcDamage`** is a byte: `128` (77 rows) is stored `0x80`, the three `-1` cells `0xFF`. (tbl:Missiles.txt:SrcDamage)
- `[C]` **Calc columns** (7: `SrvCalc1`, `CltCalc1`, `SHitCalc1`, `CHitCalc1`, `DmgCalc1`, `DmgSymPerCalc`,
  `EDmgSymPerCalc`) are s32 offsets into `misscode.bin`, −1 when blank ([calc.md](../formats/calc.md)); no stock row
  sets `DmgSymPerCalc`. Their variables are [MissCalc](MissCalc.md) rows. (tbl:Missiles.txt:EDmgSymPerCalc)
