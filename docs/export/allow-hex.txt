# The hex allowlist of the public export (plan 0070 Phase 3, owner decision 2026-11-17). Owner: architect.
#
# Hex values that are game math, not code addresses, may pass the check's X1 and X3 (an address, 6+ hex digits, a
# commit-hash shape). Each entry has a one-line reason; a change is reviewed at the next cut's redaction review.
#
#   <hex value>                       <reason>                  a named constant or an illustrative seed; matched by
#                                                               value in any spelling (0x..., bare, leading zeros)
#   section <docs path> <heading start> :: <reason>              a worked example: any hex of 6+ digits under that
#                                                               heading (to the next heading of its level or higher)
#   pin <hex value> <docs path> :: <reason>                      one value in the code image's range, allowed on
#                                                               that page only (computed by an example, not an address)
#
# Never allowed, whatever is written here: a `sub_`/`DAT_` name, a hex of 6+ digits after `_` or `+`. (An in-memory
# struct offset `Name+0x10` of up to 5 digits passes by the check's own rule: owner decision 2026-11-17.) A value in
# the code image's range, 0x00400000-0x009B9FFF (the pinned Game.exe's whole mapped image), passes only by a `pin`
# line: the loader refuses it as a plain value entry, a section does not admit it, and a pin that re/symbols.csv names
# is refused. A reviewer checks each pin's derivation. ADR-0031 lists constants of the code image (tables and their
# contents); nothing below is one: each entry is arithmetic the game does on its own seeds, or a value our own
# examples choose or compute.
# Draw values in the calculation panels of a schematic illustration folder pass by a scoped rule in the check
# (the shapes `{hi:lo}` and `{start, 666}`, which admit any value, and `lo = 0x...`, `seed 0x...`, which admit a
# value outside the image's range), not by this file.

# Named constants
6AC690C5   the RNG multiplier (the seed step is a multiply-and-add on it)
0000029A   the second word, 666, that a freshly initialised seed carries
AA55AA55   the signature word of a character save file (a file-format constant, not code)

# Illustrative seeds
0xC0FFEE   the seed of the two schematic illustrations (an illustrative input, never a game-derived seed)
00003039   12345, the illustrative seed of the randomness page's worked example
0BADF00D   a value written by hand into a save's pass-through field (save/d2s § D), an illustrative input

# Pure arithmetic of the specs (owner decision 2026-11-17, plan 0070 Phase 9): limits and masks, powers of two,
# compiler division reciprocals and the two well-known LCG constants, admitted as plain values. A domain value (a
# flag mask such as 0x3F0FF80, a magic word such as 0x01020304, a four-character code, a logged seed word) stays out.
# 0x400000 and 0x800000 are powers of two in the code image's range: refused as plain values, so not listed.
# Limits and masks (a run of set bits)
7FFFFFFF   the largest positive i32, a limit (command-line seeds, distances), not an address
FFFFFFFF   all 32 bits set: -1 as a u32, the "none" word and the mask of a full word
0FFFFFFF   the low 28 bits, a mask
F0000000   the top four bits of a word, the mask of a string hash's high nibble
FFFF0000   the high half of a word (a 16.16 position's integer part)
FFFFFF00   every bit but the low byte, a mask
FFFFF000   every bit but the low 12, a range test's mask
1FFFFF     the largest value of 21 bits, a variable-length encoding's limit
3FFFFFF    the largest value of 26 bits, a variable-length encoding's limit
# Powers of two
100000     2^20, a power of two (a bit or a scale)
200000     2^21, a power of two (a bit)
1000000    2^24, a power of two (a bit)
2000000    2^25, a power of two (a bit)
4000000    2^26, a power of two (a bit)
8000000    2^27, a power of two (a bit)
10000000   2^28, a power of two (a bit)
20000000   2^29, a power of two (a bit)
40000000   2^30, a power of two (a bit)
80000000   2^31, the sign bit of a word
# Compiler division reciprocals (a multiply-high that divides by a constant)
AAAAAAAB   the reciprocal for an unsigned division by 3
55555555   the reciprocal used for a signed division by 3 (with a subtraction)
55555556   the reciprocal for a signed division by 3
CCCCCCCD   the reciprocal for an unsigned division by 5
66666667   the reciprocal for a signed division by 5 (or 10, with a shift)
24924925   the reciprocal for a division by 7
38E38E39   the reciprocal for a division by 9 (or 18, with a shift)
88888889   the reciprocal for a division by 15 (with a shift)
68DB8BAD   the reciprocal for a division by 10000 (with a shift)
# The two well-known LCG constants (the entropy generator's multiplier and increment, a textbook pair)
19660D     1664525, the well-known LCG multiplier
3C6EF35F   1013904223, the well-known LCG increment
