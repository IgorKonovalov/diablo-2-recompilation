# The hex allowlist of the public export (plan 0070 Phase 3, owner decision 2026-11-17). Owner: architect.
#
# Hex values that are game math, not code addresses, may pass the check's X1 and X3 (an address, 6+ hex digits, a
# commit-hash shape). Each entry has a one-line reason; a change is reviewed at the next cut's redaction review.
#
#   <hex value>                       <reason>                  a named constant or an illustrative seed; matched by
#                                                               value in any spelling (0x..., bare, leading zeros)
#   section <docs path> <heading start> :: <reason>              a worked example: any hex of 6+ digits under that
#                                                               heading (to the next heading of its level or higher)
#   pin <hex value> <docs path> :: <reason>                      one value in the code image's range, allowed on
#                                                               that page only (computed by an example, not an address)
#
# Never allowed, whatever is written here: a `sub_`/`DAT_` name, a hex of 6+ digits after `_` or `+`. (An in-memory
# struct offset `Name+0x10` of up to 5 digits passes by the check's own rule: owner decision 2026-11-17.) A value in
# the code image's range, 0x00400000-0x009B9FFF (the pinned Game.exe's whole mapped image), passes only by a `pin`
# line: the loader refuses it as a plain value entry, a section does not admit it, and a pin that re/symbols.csv names
# is refused. A reviewer checks each pin's derivation. ADR-0031 lists constants of the code image (tables and their
# contents); nothing below is one: each entry is arithmetic the game does on its own seeds, or a value our own
# examples choose or compute.
# Draw values in the calculation panels of a schematic illustration folder pass by a scoped rule in the check
# (the shapes `{hi:lo}` and `{start, 666}`, which admit any value, and `lo = 0x...`, `seed 0x...`, which admit a
# value outside the image's range), not by this file.

# Named constants
6AC690C5   the RNG multiplier (the seed step is a multiply-and-add on it)
0000029A   the second word, 666, that a freshly initialised seed carries
AA55AA55   the signature word of a character save file (a file-format constant, not code)

# Illustrative seeds
0xC0FFEE   the seed of the two schematic illustrations (an illustrative input, never a game-derived seed)
00003039   12345, the illustrative seed of the randomness page's worked example
